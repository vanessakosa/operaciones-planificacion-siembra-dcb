# Identidad visual · obligatoria en todo documento generado

> Aplicar sin excepción antes de crear cualquier informe, protocolo, presentación o PDF para DCB.

## Tipografías

| Tipografía | Uso |
|---|---|
| Lora Regular | Cuerpo, tablas, párrafos |
| Lora Italic | Subtítulos, notas, fechas, énfasis suave |
| Selva | Solo portadas y piezas de marketing. Si no está disponible → Lora |

**Excepción operativa:** los PDF que van a los operarios usan **Helvetica sin itálicas**,
porque priman legibilidad en campo y tamaño de tabla sobre estética de marca.

## Paleta

| Color | HEX | Uso |
|---|---|---|
| Beige claro | `#F5F0E8` | Fondo principal, header de tablas, secciones |
| Crema suave | `#FAF7F3` | Filas alternas |
| Blanco | `#FFFFFF` | Fondo limpio, filas principales |
| Negro suave | `#1A1A1A` | Tipografía principal |
| Gris oscuro | `#555555` | Texto de headers de tabla |
| Gris | `#888888` | Notas al pie, textos secundarios |
| Palo de rosa | `#EDD5D5` | Acento — diagramas, alertas suaves |
| Verde salvia | `#C8DCC8` | Acento — indicadores positivos, disponibilidad |
| Rojo alerta | `#C0392B` | Solo mermas críticas y alertas urgentes |
| Separador beige | `#D0C8B8` | Líneas divisoras |

## Estructura estándar

**Portada:** logo centrado 80–100 px (`IMG_6001.png`) · título Lora 28–32 centrado ·
subtítulo Lora Italic 20–22 gris · fecha y versión Lora Italic 17 gris · separador beige.

**Cuerpo:** H1 Lora 24pt mayúsculas con línea inferior `#D0C8B8` · H2 Lora Italic 21pt `#555555` ·
cuerpo Lora 20pt `#1A1A1A` · bullets con guión largo (—), nunca círculos ·
headers de tabla fondo `#F5F0E8` texto `#555555` · filas alternas blanco/crema ·
pie de página Lora Italic 16–18pt gris centrado.

## Lo que NUNCA debe aparecer

- Fondos oscuros o negros en tablas, headers o secciones
- Verdes corporativos (`#1A5C38` o similares), azules, morados, naranjas
- Arial, Calibri u otra sans-serif como principal
- Negritas excesivas — solo datos clave puntuales
- Sombras, degradados, efectos decorativos

> **Nota para Claude Code:** hay un script de Apps Script que pinta el header de
> `EXPORT_CALENDARIO` en `#1A3A2A` con texto blanco. Eso viola la identidad visual.
> Es una hoja técnica interna, no un entregable — pero si alguna vez se convierte en algo
> que ve un cliente, hay que corregirlo a `#F5F0E8` / `#555555`.

## Tono de comunicación

- Elegancia sin ostentación — el lujo está en la simplicidad y la claridad
- Datos sin ambigüedad, directo al punto
- Lenguaje cercano, primera persona cuando aplica
- Terminología ligada al cultivo, la naturaleza y la artesanía
